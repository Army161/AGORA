## The problem

Every AI surface is single-player. Open Claude Code and Claude Desktop side by side and you have
two capable agents that cannot see each other — no shared task list, no idea who is editing which
file, no memory of what the other just did.

Coordination collapses into copy-pasting context between windows, and the real project state ends
up living in the operator's head.

## What Agora is

One MCP server, one workspace folder. Every surface that points at the same folder is in the same
room — that is the entire trick. State lives on disk, not in any single agent's context window.

```
   claude.ai   Cowork   Claude Code   Chrome   Design
        └─────────┴──────────┼──────────┴────────┘
                             │  MCP
                      agora_mcp.py          19 tools
                             │
                        store.py            mutex · atomic writes · TTL leases
                             │
                    ~/.agora/main/          events.jsonl · tasks · agents · locks · board.md
```

## Why it holds up

Coordination is a **state** problem, not a **model** problem. A stronger model does not stop two
agents writing to the same file at the same time — it just does it more confidently.

Humans solved this long ago with boards, tickets, check-outs and handover docs: cheap external
state anyone can read to find out who owns what. Agents need the same primitives, but with
machine-native semantics — because agents do not notice a stale ticket. They crash, get closed
mid-task, or quietly stop.

<Note>
**Every claim is a lease with an expiry.** An agent that dies mid-task blocks work for at most its
TTL, then the task returns to the pool automatically. No human cleanup required.
</Note>
